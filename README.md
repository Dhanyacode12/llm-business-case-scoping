# LLM Business Case Scoping

Scoping documents from the *Applied LLMs for Business Cases* exercise. The goal is to act as a Product Manager and frame vague "use AI" requests correctly **before** any modelling: what the problem is, whether ML is even the right tool, what data and methods fit.

| Scenario | Document | One-line take |
| --- | --- | --- |
| A3 – Support Ticket Overload | [scoping-A3-support-tickets.md](scoping-A3-support-tickets.md) | Unsupervised topic discovery first, then weakly supervised routing; humans stay in the loop. |
| B5 – Executive Dashboard Automation | [scoping-B5-executive-dashboard.md](scoping-B5-executive-dashboard.md) | Mostly decomposition and anomaly detection, not ML; the LLM only narrates verified numbers. |

Each document has six sections: Problem Clarification, Problem Type, Data Science Scope, Modeling Approach, Use of LLMs (Reflection), and Unknown Methods Discovery.

Presentation notes (about 3–4 minutes per scenario): [presentation-talking-points.md](presentation-talking-points.md)
